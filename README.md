# Job Search Telegram Mini App

A Telegram Mini App built with:

- Frontend: Next.js
- Backend: FastAPI
- Database: MongoDB

## Features
- Job listing
- Search jobs
- Apply to jobs
- Telegram Mini App integration

## Run Project

### Backend
```bash
cd backend
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
